How to read this dashboard

The CSV contains yearly observations from 1995 to 2024. To make a destination ranking, this dashboard uses the most recent available observation for each country or territory. The latest year is not the same everywhere, so these rankings are useful for exploring differences—but they are not a perfectly synchronized comparison.

1 · Compare destinations

The ranking shows each place’s latest reported arrivals. Check the “Original data year” column to see when that value was recorded.

2 · Look at the distribution

The distribution chart groups destinations into arrival-volume bands. It helps show whether a few destinations dominate the dataset or whether values are more evenly spread.

3 · Keep the limits in mind

Tourist-arrival definitions and reporting years may differ. A sum of country values is not a single-year world total, and arrivals do not necessarily represent unique individuals.
